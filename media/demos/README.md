# Your own demo clips

Put a short video of each movement in this folder and HUNT READY 30 will show it in the exercise guide automatically, in place of the YouTube demo. Nothing else needs to change.

## How to add a clip

1. Film the movement: phone on a tripod, side view, whole body in frame, 10–25 seconds, a few clean reps.
2. Export as **MP4 (H.264)**. Keep each file under about 15 MB so it loads fast on a phone. Vertical or landscape both work.
3. Name the file exactly as shown below and upload it to this folder on GitHub (`Add file → Upload files`).
4. Optional: add a poster image with the same name and a `.jpg` extension (for example `hip-hinge.jpg`). It shows before the clip plays.

The app checks for the file the next time you open that exercise guide. If a clip is missing, the guide simply keeps showing the drawing and the YouTube demo.
